BIBLIOTECAS USADAS NO SCANNER:

presidio-analyzer - Detecta CPF, CNPJ, RG, cartão, e-mail e número de ofício por padrões e contexto.
spacy - Fornece o modelo de linguagem português usado pelo Presidio (pt_core_news_sm).
pdfplumber - Leitura e extração de PDF para análise.
pytesseract - Integra o Python ao mecanismo Tesseract para OCR de PDFs digitalizados e imagens.
Pillow - Abre/prepara imagens e permite renderizar páginas do PDF para OCR.
reportlab (opcional) - Gera relatório em PDF com dados falsos para testar análise.

O scanner não usa mais modelo de linguagem externo: não precisa de OPENROUTER_API_KEY,
internet, openai, instructor, httpx, dotenv nem pydantic. O relatório é montado
deterministicamente a partir da interseção regex + Presidio.

Comando para instalar as bibliotecas necessárias:
python -m pip install presidio-analyzer spacy pdfplumber pytesseract Pillow
python -m spacy download pt_core_news_sm

IMPORTANTE: pytesseract é apenas a ponte Python. Também instale o Tesseract OCR para Windows,
incluindo o idioma português (por). Se o executável não estiver no PATH, configure TESSERACT_CMD
com o caminho completo de tesseract.exe (por exemplo, C:\Program Files\Tesseract-OCR\tesseract.exe).
